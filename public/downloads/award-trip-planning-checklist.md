# Award Trip Planning Checklist

## Trip basics
- [ ] Origin airport(s)
- [ ] Destination airport(s)
- [ ] Travel date range
- [ ] Number of travelers
- [ ] Cabin preference
- [ ] Nearby airports acceptable

## Award search
- [ ] Search nonstop options
- [ ] Search one-stop options
- [ ] Check nearby origin airports
- [ ] Check nearby destination airports
- [ ] Compare cash fare
- [ ] Record points + taxes/fees

## Before transferring points
- [ ] Confirm award is actually bookable
- [ ] Confirm transfer partner and transfer ratio
- [ ] Check for transfer bonus
- [ ] Review transfer timing
- [ ] Confirm transfer is not reversible
- [ ] Screenshot or record award details

## Backup plan
- [ ] Save 1–2 alternate flights
- [ ] Review cancellation/change rules
- [ ] Check what happens after a schedule change
